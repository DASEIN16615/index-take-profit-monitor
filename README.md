# 指数监控 Index Monitor

每日自动评估 **纳指100 / 标普500 / 沪深300 / 中证500** 的估值与趋势,输出两个独立信号:

- **估值评分 → 新资金投入比例**(仓位调节器)
- **趋势确认 → 存量止盈**(严格触发,买卖开关)

## 架构

```
Cloudflare Workers cron (工作日 09:00 北京时间,可靠触发)
   ↓ 调用 GitHub Actions dispatch API
GitHub Actions 执行 index_monitor.py (云端,不依赖本地设备)
   ↓
脚本发邮件报告 (HTML 卡片,彩色状态)
```

- 触发端:Cloudflare Worker,`cloudflare_worker/`(wrangler.toml + src/index.js),密钥存 Cloudflare 加密环境变量(`GH_TOKEN` GitHub 精细令牌、`KEY` 手动触发口令)
- 执行端:GitHub Actions workflow `.github/workflows/daily.yml`,运行脚本并发邮件
- 邮件凭据:`SMTP_USER` / `SMTP_CODE` 存 GitHub Actions Secrets,不落代码

## 信号规则(估值 × 趋势 双轴)

**核心:估值管"新钱投多少",趋势管"存量卖不卖"。**

### ① 估值 → 新资金比例

各指数用可用指标的**历史分位**加权评分(分位越高越贵,缺失指标自动归一化):

| 指数 | 评分成分 |
|---|---|
| 纳指100 | PE 分位(×1.0;PB/股息率无公开免费源) |
| 标普500 | PE 0.4 + PB 0.3 + (1−股息率分位) 0.3 |
| 沪深300/中证500 | PE 0.5 + PB 0.5 |

股息率分位已反转(分位高=便宜)。评分 → 定投比例:

| 评分 | 新资金投入 |
|---|---|
| < 40% | 100% |
| 40–60% | 75% |
| 60–75% | 50% |
| 75–85% | 25% |
| ≥ 85% | 0% |

### ② 趋势 → 存量止盈(严格)

- **评分 ≥ 95%** → 分批止盈
- **评分 ≥ 90% 且 趋势转弱** → 分批止盈(转弱 = 收盘连续 ≥2 日低于 SMA200 且 SMA200 二十日斜率为负)

"偏贵"只减投入,不卖;"极高估值 + 趋势破位"才卖,永远分批(每次 1/3,间隔 10% 涨幅),卖出后继续定投。

### ③ 盈利增长(信息展示)

标普500 显示 EPS 同比(multpl);纳指/A股无可靠免费源时标 N/A。指数层面不用 PEG(盈利增速接近 0 时失真)。

## 数据源

| 数据 | 来源 |
|---|---|
| 美股价格/趋势(SMA200) | Yahoo Finance chart API |
| 纳指估值 | worldperatio(PE + 10Y 分位) |
| 标普估值 | multpl(PE/PB/股息率/EPS 历史表) |
| A股价格/趋势 | 新浪日线接口 |
| A股估值 | 蛋卷基金(PE/PB 分位 + 股息率) |

口径说明:同一指数不同源 PE 可能差 10-15%(盈利聚合方式不同),报告标注来源与数据日期;美股 TTM 盈利随财报更新会变动,PE/分位可能短期明显变化,属数据更新而非错误。

## 本地运行

```bash
python index_monitor.py            # 纯标准库,零依赖
python index_monitor.py --verbose  # 调试
```
